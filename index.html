    Free online document tools

    Doxemi is a collection of small, focused tools for the file formats people work with every day: Word documents, plain text files, rich text files, spreadsheets saved as CSV, and Excel workbooks. Instead of one large, complicated program, Doxemi breaks document work into single-purpose tools — a word counter, a format converter, a metadata viewer — each doing one job clearly.

    Supported formats

    Doxemi currently supports DOCX (Microsoft Word), TXT (plain text), RTF (rich text), CSV (comma-separated values) and XLSX (Excel workbooks). Each format has its own set of tools, reachable from the navigation bar or the category cards above.

    DOCX, TXT and RTF tools

    The DOCX tools let you preview a Word document in the browser, pull out its plain text or HTML, count words and paragraphs, and inspect the document properties stored inside the file. TXT tools cover the everyday text tasks: counting words, characters and lines, changing letter case, tidying up messy whitespace, and reformatting paragraphs. RTF tools read rich text files and extract their text content, since RTF is a format many people still receive but few apps open directly.

    CSV and XLSX tools

    CSV tools handle comma-separated data: viewing it as a table, converting it to and from JSON, pulling out specific columns, counting rows, and cleaning up blank or duplicate rows. XLSX tools work with real Excel workbooks — viewing sheets, converting between XLSX and CSV, extracting a single sheet, and reading workbook metadata.

    Processing happens in your browser

    Most Doxemi tools read your file and do their work directly in your browser, using JavaScript, rather than sending the file to a server. That means a file you open in the DOCX Viewer or the CSV Cleaner generally never leaves your device. A small number of tools are marked where this isn't the case, or where a feature is still being built.

    Common workflows

    People typically chain a couple of tools together: extracting text from a DOCX file before pasting it somewhere else, cleaning a CSV export before importing it into another system, or checking a document's word count before submitting it. Related tools are linked at the bottom of every tool page to make that easier.

    Frequently asked questions

    What document formats does Doxemi support?

    Doxemi supports DOCX, TXT, RTF, CSV and XLSX files, along with general tools that work across formats, like a file size or MIME type checker.

    Can I use Doxemi on mobile?

    Yes. Doxemi is built to work on phones, tablets and desktops, including uploading files from a mobile device's file picker.

    Are my documents uploaded to a server?

    Most tools process your file entirely in your browser and never send it anywhere. Any tool that works differently says so on its own page.

    Can Doxemi convert DOCX files?

    Yes. DOCX files can be converted to plain text and HTML in-browser, and to PDF using your browser's print dialog.

    Can Doxemi process CSV and XLSX files?

    Yes. CSV tools cover viewing, converting and cleaning CSV data, and XLSX tools cover viewing, converting and extracting data from Excel workbooks.
